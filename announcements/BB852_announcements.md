# BB852 itslearning announcements

Standard announcements for BB852, posted on itslearning every year. This folder is not part of the course book: bookdown only builds the `.Rmd` files in the repository root, so nothing here appears on the website.

Keep each announcement short and point to the course book for details, so the rules live in one place (the book). Fill in the `[square-bracket]` placeholders each year before posting. Nothing about assessment content goes here: this repository is public.

| Announcement | When to post |
|---|---|
| Welcome and getting set up | About one week before the first lecture |
| MCQ exam | About two weeks before the exam, once the date and room are confirmed (from Pia, exam planning) |

## 1. Welcome and getting set up

**Title:** Welcome to BB852: please get R ready before the first session

> Welcome to BB852: Data handling, visualisation and statistics!
>
> This course trains you to handle your own data, explore it graphically and analyse it statistically in R, with skills you can take straight into your thesis. Everything you need is in the course book: https://jonesor.github.io/BB852_Book/. Start with the Preface, which explains how the course works, what I expect from you, and how you are assessed.
>
> **Please do this before the first session.** Every year we lose valuable class time sorting out software problems, so please get set up in advance by working through the "Getting set up" chapter of the course book: https://jonesor.github.io/BB852_Book/getting-set-up.html. In short:
>
> - remove any old version of R and install the latest R and RStudio;
> - check that R works and reports a recent enough version;
> - install the course packages;
> - download the course data.
>
> If you get stuck, write down the exact error message and bring it to the first session (or email me before then).
>
> Please bring a fully charged laptop to every session: the practicals are hands-on.
>
> See you on [day, date]!
> Owen
